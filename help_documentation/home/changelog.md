# Changelog on Home

The Home Changelog component shows recent IMAGE_GEN development notes and release information.

Selecting an entry opens the note with the same shared Markdown capability used by Help Center. The Changelog component no longer owns its own Markdown parser or document dialog.

The changelog can still fall back to the files bundled with the installed IMAGE_GEN build when the public repository is unavailable.
