# Help Center

The Help Center keeps IMAGE_GEN's public user documentation inside the WebUI. Open it from the Home Help Center component, browse the topic tree, or search for a topic.

## Search

Search suggestions begin after you type at least three characters. This avoids showing a large result list for one- or two-letter fragments. Search covers topic titles, summaries, keywords, category names, and the public Markdown body.

## Topic tree

Topics are grouped by category and subcategory. Selecting a topic opens it in the shared Markdown browser without exposing IMAGE_GEN's private `docs/` workspace.

## Related topics

Each help file can declare related topics. Related guides appear below the current document so you can continue through a workflow without returning to the category tree.

## Media and links

Help topics can include repository-owned images and videos. External resources are shown as explicit links and open in a new browser tab.
