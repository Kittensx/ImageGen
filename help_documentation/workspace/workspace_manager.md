# Workspace Manager

Workspace Manager controls the arrangement of registered components on supported IMAGE_GEN pages.

Components declare a stable identity, compatible pages, presentation variants, size limits, and any shared capabilities they require. For example, Changelog subscribes to the shared Markdown capability, while Help Center subscribes to shared Markdown and media capabilities.

Changing a component's base width or presentation changes the saved workspace. Responsive preview modes show the effective layout at different container widths without overwriting those base values.
