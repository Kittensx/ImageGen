# Responsive Workspace Layouts

IMAGE_GEN workspaces adapt to the actual workspace container width rather than assuming a particular monitor size.

The saved layout remains portable. Wide, Standard, Compact, and Narrow modes derive effective spans and presentation variants from the same base layout so a workspace can move between window sizes without maintaining four unrelated pixel layouts.
