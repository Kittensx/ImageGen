Hires / Second Pass The base image is sampled first, its latent is enlarged, and a second denoising pass refines the selected hires dimensions.
Second-pass dimensions: calculated from the base image.
Denoising strength controls how much freedom the second pass has to change the upscaled image. Refinement steps control how many denoising transitions are executed. Fixed executed steps: 20 requested · 50 internal schedule transitions · 20 executed.
The second pass inherits the base sampler, scheduler, and CFG settings. The low-resolution artifact is decoded from the exact in-memory base latent used by the hires pass; it is not generated a second time.
