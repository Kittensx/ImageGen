These settings are fixed after the worker initializes. Saving a different value marks it pending; it does not become active until a full ImageGen restart.

Active and pending values are shown in Runtime Status. Browser refresh alone cannot activate these changes.

Per-Job Memory Runtime

Diagnostics

Diagnostic decode is off by default. When enabled, diagnostics may use the VAE to decode requested sampler-trace previews. Final output decoding and live preview are unaffected.

Failures-only keeps lightweight tensor shape/dtype/device summaries for failure bundles. Every-run adds timing/event exports without full tensor statistics. Deep tensor analysis adds GPU-synchronizing tensor statistics, sampler traces, and output-quality reports and should be used only for targeted troubleshooting.

Recent Outputs

New outputs still refresh immediately on job events. Slower idle refresh reduces thumbnail backlog and keeps queue actions responsive.

Prompt Shortcut Profiles

Assign readable keyboard shortcuts to prompt operators without editing JSON. Built-in profiles are read-only; duplicate one to customize it.

Keyboard shortcuts

Enter the shortcut text for each operator. Separate multiple accepted aliases with commas. Blank operators are not enabled by this profile.

Symbol palette shortcuts

Customize the keyboard text inserted by palette helpers such as attention, de-emphasis, weights, alternates, and schedules. Operator-backed helpers continue to use the shortcut mappings above.

Parser output mappings

These values control what each compatible parser receives after a shortcut is translated. Most profiles can leave the duplicated defaults unchanged.
